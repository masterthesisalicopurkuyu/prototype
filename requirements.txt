# Provider-Schicht:
#   fastapi      – REST-Provider mit Auto-OpenAPI-Spec (Q2: OpenAPI 3.0+)
#   uvicorn      – ASGI-Server für FastAPI
#   pydantic     – Datenmodelle (über FastAPI mitinstalliert)
#   mcp[cli]     – MCP Python SDK, offizielle Referenzimplementierung (Q3)
#
# Agent-Schicht:
#   groq         – LLM-Provider mit kostenlosem Function-Calling-Tier
#                  (statt Gemini, da Gemini Free Tier in EU nicht verfügbar)
#
# Integration REST:
#   httpx        – Async HTTP-Client für REST-Calls
#
# Keine Agent-Frameworks (kein LangChain, kein AutoGen):
#   Begründung: Wohlin et al. (2012, Kap. 5) – Minimierung von
#   Confounding Factors. Framework-spezifische Abstraktionen würden
#   den direkten Paradigmenvergleich verfälschen.
